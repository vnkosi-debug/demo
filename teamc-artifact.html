The Core Four

The Four Major Agentic Protocols

The backbone of the Agentic Stack's runtime trust fabric

MCP Model Context Protocol Championed by Anthropic
Stabilizes Model Inputs
Versioned, slot-based context packaging that ensures every reasoning cycle starts with predictable, verifiable inputs. Guards against context drift.
ACP Agent Communication Protocol OpenAI + OSS Community
Makes Communication Traceable
JSON-native heir to FIPA ACL standards. Binds identity, correlation, and state into every message — traceable, replayable, and provable.
A2A Agent-to-Agent Protocol Google DeepMind
Keeps Autonomous Peers in Sync
Extends ACP with task IDs, declared capabilities, progress updates, and checkpointed state handoff. Turns free-form chatter into synchronized execution.
ANP Agent Network Protocol W3C / IBM / Microsoft
Carries Trust Beyond Your Walls
Uses DIDs, machine-readable capability disclosures, and federated policy enforcement for cross-organization, cross-jurisdiction trust.

Gaps

Protocolization Candidates

Where production agents still fail — and what to do about it

1
Retrieval Provenance Protocol
Gap
No shared schema, no cryptographic proof — "trusted" info has no verifiable trail in regulated environments
Fix
Attach origin, timestamp, trust score + signature to every retrieved fact, enforced at the protocol level
2
Memory Access Protocol
Gap
Custom session stores make pause/resume/handoff impossible — brittle monoliths that break when interrupted
Fix
Common contract for temporal state storage, resumption, and transfer with versioning and TTL enforcement
3
Action Invocation Contract
Gap
Approvals scattered across logs — governance relies on human habit rather than systemic guarantee
Fix
Bind execution to required oversight — approvals must be enforceable, verifiable, and inseparable from the action
4
Governance & Tool Safety Contracts
Gap
Tools can't declare required environment — risky tools run with same privileges as safe ones
Fix
Tools declare execution class and requirements in advance; runtime enforces them — declarative isolation by protocol

Live Application

Real Demo: Protocol Execution in Motion

Demo Overview: This walkthrough runs on our real implementation in T.py, where agents collaborate through trust-preserving protocols. Documents carry provenance (origin, timestamp, trust score, signature), context is packaged into MCP slots, ACP envelopes keep messages traceable, and tools execute through sandbox classes. Live protocol logs stream in the Flask dashboard while the system generates slides, summaries, PDF reports, and analysis JSON outputs.
1
Retrieve with Provenance Files processed with Retrieval Provenance include origin, timestamp, trust score, and cryptographic signature before they enter the agent workflow.
2
Package Context via MCP Context is written into stable MCP slots containing structured excerpts, metadata, and task intent, ensuring each reasoning cycle starts from versioned, predictable inputs.
3
Exchange ACP Messages Agents (ResearchBot → ContentWriter → AnalysisAgent) communicate through validated ACP envelopes with identity, correlation, and traceable state.
4
Execute Safely via Sandbox Tools run under explicit execution classes (safe, restricted, privileged) with runtime enforcement of declared requirements.
5
Generate Outputs + Live Visibility The system produces summaries, slides, PDF reports, and analysis_*.json files while real-time protocol logs are visible in the Flask dashboard.
